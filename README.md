# Веб-приложение с консолью для запуска кода на Python и C++

Проект **Console** представляет собой веб-приложение, которое предоставляет интерактивную консоль для выполнения и тестирования кода на языках программирования **Python** и **C++**. Это удобный инструмент для разработчиков, позволяющий быстро проверять фрагменты кода без необходимости настройки локальной среды.

## Функционал

- **Поддержка Python и C++**: Возможность запускать и тестировать код на двух популярных языках программирования.
- **Интерактивная консоль**: Удобный интерфейс для ввода и выполнения кода.
- **Безопасность**: Запуск кода в изолированной среде для предотвращения потенциальных угроз.

## Как это работает

1. Пользователь вводит код на Python или C++ в текстовое поле.
2. Код отправляется на сервер, где выполняется в изолированной среде.
3. Результат выполнения (вывод, ошибки или время работы) возвращается пользователю и отображается в интерфейсе.

## Технологии

Проект разрабатывается на языке **Java**.
